What this is / what it trades Mail, and you already know how to use mail: sender is the agent, subject is the claim, snippet is the first check, and the row you are on opens in place with the evidence. It is the only shape that stays comfortable at thirteen waiting, and the only one where a keyboard clears the queue without the mouse. Trades: it is the closest of the four to the list of database rows you already dislike — one line means one line, so the claim gets truncated and nuance dies in the ellipsis — and picking multiple branches to approve at once is exactly the blind bulk approve the spec rules out unless every picked packet has been opened.

How it held up in Chaos — survives, on one condition The one thing D sells is density — thirteen decisions on a screen — and Chaos's construction language is a 2px ink outline plus a 3px drop bevel on every plate. Give each row its own plate and you spend about 7px a row and turn a list into a stack of buttons; D's only advantage is gone. The condition is therefore: the list is ONE plate and the rows are ink rules inside it. That is not a compromise, it is what a 16-bit item menu actually is, and the density holds at exactly the row height Calm uses. The focused row takes the gold plate with the sheen — the same plate the board already uses for “this one needs you” — and the key hints become the command bar along the bottom in 8px pixel type.

What it cost: dimming. Calm greys out a merged row and a child row and you read the difference instantly. On purple, grey lands under 3:1, so every quiet state has to be re-cut from the skin's own lilac ramp — which works, but the gap between a live row and a settled one is genuinely thinner here than it is in Calm. In the shape whose whole job is scanning, that is a real cost, not a nitpick.
